# Zambo MCP - Tool Catalog

Zambo is the verifiable work layer for AI. Endpoint: https://zambo.dev/mcp

```json
{"mcpServers":{"zambo":{"url":"https://zambo.dev/mcp"}}}
```

**153 tools**, with 35 on the default surface. Flagship product: HANDOVER.

- Free: 20 free calls per day, then they upgrade.
- Day Pass: $0.99 USDC on Base for 24 hours.
- Zambo Pass: $29 for 30 days, one payment.
- $ZAMBO holders: $19 for 30 days.

Source: tools.json in this repo. Descriptions are one-line summaries from tools.json.
