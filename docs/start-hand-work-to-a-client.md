# Hand work to a client so they can see it is done

The hard part of client work is not doing it. It is proving it is done, in a way the client can check without a meeting, a screenshot thread, or a "trust me."

Zambo's handover does that in one link.

## Do this

1. Finish the work with your AI like you normally would.
2. Say: "Use Zambo to hand this over."
3. You get one handover link with the full record attached: what was done, the results, and the receipts behind them.
4. Send the link to the client. They open it and see the work and its proof in one place.

## Why clients like it

- One link instead of a pile of files and screenshots.
- Every piece of work in the handover carries its receipt, so the client can check any item themselves.
- If there is ever a disagreement about what was delivered, the record is right there, unchanged since the work was done.

## Why you will like it

You stop re-explaining finished work. The handover is the explanation, and it holds up because the receipts behind it can be checked by anyone.
