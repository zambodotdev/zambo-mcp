# Contributing

Documentation fixes, reproducible protocol issues, compatibility notes, and safe examples are welcome.

Before opening a change:

1. Verify commands against the current public endpoint.
2. Use 153 tools as the current tool count, and let MCP discovery provide the exact count.
3. Do not claim universal compatibility, external-outcome verification, unlimited upstream usage, or complete security.
4. Keep examples free of secrets and personal data.
5. For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
